Pug — Independent AI Co-Host & Mascot Checklist

Project: PapaThaiGG.com / Pug  |  Updated: August 6, 2026
Local independent AI co-host: 3D avatar on stream, reacts to chat & in-game moments, takes commands, talks or types back.

Vision (Sal’s)

  • Pug is an independent AI co-host and mascot, not a passive overlay.
  • Body: 3D avatar (current shell + optional second Warudo avatar).
  • Brain: Local LLM via Ollama on the streaming PC.
  • Personality: Sarcastic, tactical, Thailand Base Camp energy.
  • Listen: Chat + voice commands from Sal.
  • Speak / type: TTS and/or on-stream chat replies.
  • React to the game: e.g. get shot → Pug freaks out / comments.
  • Website: papathaigg.com “Meet Pug” tells the story.

Build order: Chat reactions → Voice commands → Game-event reactions.

Phase 0 — Prep

  • Confirm GPU/VRAM budget for Ollama + game + Warudo
  • Install / update Ollama; pull base model (+ optional Dolphin)
  • Write Pug system prompt (tone, short replies, stream rules)
  • Choose primary chat platform; Warudo project ready
  • Decide if a second Warudo-optimized avatar is needed

Phase 1 — Brain online

  • Ollama answers with Pug’s prompt from a terminal
  • Cap replies to 1–2 sentences for live play
  • Save winning model + prompt in config/notes

Phase 2 — Avatar body (Warudo)

  • Avatar loads; idle/talk/react mapped; TTS voice chosen
  • OBS layout keeps Pug visible without covering critical HUD
  • Optional second avatar for Warudo-only look

Phase 3 — Chat co-host

  • Read live chat; filter spam; rate-limit replies
  • @Pug / trigger words for direct questions
  • Spoken TTS path + optional typed chat path + mute toggle

Phase 4 — Voice commands

  • Push-to-talk Sal → STT → short spoken confirm
  • v1 commands: read that / hype / quiet / what did chat say

Phase 5 — In-game reactions

  • Hotkey / Streamer.bot events first (death, clutch, wipe, etc.)
  • Preset lines + light LLM paraphrase
  • Deeper game-state hooks only after that; never tank FPS

Phase 6 — Website & brand

  • Meet Pug page matches real capabilities
  • Mobile hero/buttons stay readable (Aug 6, 2026 pass)

Phase 7 — Stream-ready polish

  • 30+ min dry-run; temps/FPS OK; emergency stop documented
  • Backup if Ollama dies (silent avatar or canned lines)
Next one thing: Install Ollama → lock Pug’s system prompt → wire one chat source to a spoken Warudo reply.
