Game awareness — what’s truly possible

LevelHow Pug “knows”When
Easy ✓Chat · your voice · Stream Deck button you pressPhase C
Medium ✓Game hooks/APIs for specific gamesPhase C–D
Animations ✓Warudo dance/sad/hype — fired by any event abovePhase C
Hard △AI “watches” game video — experimental, not reliable aloneFuture test

Pug won’t auto-react to a fight loss with zero setup. We wire event pipes (chat, voice, hotkeys, game signals) → Ollama → TTS → Warudo animation. That’s how victory dances and “nice try, Boss” become real.

Vision experiment — “watch the game” (future · optional)

Fun to try · not for tonight. AI vision on game capture — slow, GPU-heavy, may not work well. OK to disable if flaky.
Steam Deck toggle: tap ON before a big fight → Pug/Pugsan watch screen and may react · tap OFF when done — not on all the time (saves GPU). Works alongside chat/mic/hooks, not instead of them.
